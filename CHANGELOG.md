# Changelog

## 1.0.0-beta.1

First beta of the rebuilt Simplify. Updates come from the Pelican Hub only.

- Overview of all your servers with live CPU, memory and disk, search, and start, stop, restart and kill from each tile.
- Show all servers, only yours or only others'; sort by name or date; cards, compact or list. Saved per account.
- Your own server groups with a name and colour.
- Server page: address to join and SFTP login above Pelican's console, with copy buttons.
- Add-on settings page in the admin area. Add-ons plug in through one small contract (see ADDONS.md).
- New logo.
